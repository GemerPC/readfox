# AI-функции ReadFox на Cloudflare Workers AI

Worker использует нативный binding Cloudflare Workers AI, основную модель
`@cf/meta/llama-4-scout-17b-16e-instruct` и резервную
`@cf/zai-org/glm-4.7-flash`. Внешний API-ключ не требуется: русская тема,
контекстный перевод слов и генерация английских текстов обрабатываются внутри
Cloudflare.

Доступны четыре маршрута:

- `/translate` переводит русскую тему на английский перед генерацией текста;
- `/translate-word` возвращает значение выбранного слова в контексте, перевод
  всего предложения и точный соответствующий фрагмент;
- `/prepare-text` пакетно готовит переводы и транскрипции всех кликабельных слов,
  сверяет переданный список с токенизацией предложения и восстанавливает пропуски
  резервной моделью;
- `/generate` создаёт учебный английский текст по теме или выбранным словам.

Worker проверяет, что перевод смыслового слова действительно присутствует в переводе
предложения. Для артиклей и вспомогательных глаголов, которые естественно опускаются
в русском, возвращается краткая грамматическая роль без выдуманного фрагмента.
Пропуски сначала восстанавливаются через бесплатную модель OpenRouter
`nvidia/nemotron-nano-9b-v2:free`, используя секрет `OPENROUTER_API_KEY`. Если она недоступна,
используется контекстный машинный перевод Google, затем официальный MyMemory API: целевое слово
помечается внутри полного предложения, поэтому из машинного перевода извлекается
именно контекстный русский фрагмент. Если маркеры не сохранились, запрос передаётся
резервной AI-модели. Полностью подготовленные пакеты сохраняются в Cloudflare Cache
на 30 дней, поэтому повторное открытие текста не расходует AI-лимит.

## Развёртывание

1. Авторизуйтесь в Cloudflare: `npx wrangler login`.
2. Из корня ReadFox выполните `npx wrangler deploy`.

Binding `AI` описан в корневом `wrangler.jsonc`:

```json
"ai": {
  "binding": "AI"
}
```

Разрешённые адреса сайта перечислены в `worker/src/index.mjs`. При смене домена
обновите `ALLOWED_ORIGINS` и повторите deploy.
